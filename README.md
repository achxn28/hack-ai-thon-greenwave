# GreenWave

A responsive Next.js and Tailwind CSS landing-page starter for GreenWave, a fan-first concept for smarter stadium concessions.

## Getting started

Requires Node.js 18.17 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Included

- Next.js App Router with TypeScript and Tailwind CSS
- Responsive, accessible product landing page and navigation
- Interactive sample concession wait-time selector
- Email interest form with client-side validation (prototype only; no data is stored or sent)
- GreenWave brand color tokens and page metadata

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run typecheck` — TypeScript check
